# Web Mirror — утилита для офлайн-зеркалирования сайтов

Программа на Go, которая рекурсивно загружает веб-сайт, сохраняя HTML‑страницы и все связанные ресурсы (изображения, скрипты, CSS‑файлы). Результат — локальная копия сайта, готовая для просмотра без доступа в интернет.

## Возможности

- **Рекурсивный обход** страниц в пределах одного домена.
- **Скачивание ресурсов**: `img`, `script`, `link[rel="stylesheet"]`.
- **Перезапись ссылок** в HTML на локальные пути (относительные).
- **Контроль глубины** рекурсии (ограничение количества переходов).
- **Параллельные загрузки** с настраиваемым уровнем конкурентности.
- **Защита от дублирования** — каждый URL загружается только один раз.
- **Корректная работа** с относительными и абсолютными URL.
- **Таймауты** на HTTP‑запросы.
- **Сохранение структуры** — файлы раскладываются по подкаталогам `домен/путь/файл`.

## Установка

### Требования
- Go версии 1.16 или выше.

### Сборка из исходников
```bash
git clone https://github.com/yourusername/web-mirror.git
cd web-mirror
go build -o web-mirror
Установка через go install
bash
go install github.com/yourusername/web-mirror@latest
Использование
bash
./web-mirror [флаги] <URL>
Флаги
Флаг	Значение по умолчанию	Описание
-depth	2	Максимальная глубина рекурсии: 0 — только начальная страница, -1 — без ограничений.
-concurrency	5	Количество одновременных HTTP‑запросов.
-output	./site	Директория для сохранения зеркала.
-timeout	10	Таймаут на один запрос (секунды).
Примеры
Скачать сайт на глубину 1 (стартовая страница и прямые ссылки с неё):

bash
./web-mirror -depth 1 https://example.com
Полное зеркало сайта (без ограничения глубины, 10 одновременных загрузок):

bash
./web-mirror -depth -1 -concurrency 10 https://example.com
Только главная страница (без перехода по ссылкам):

bash
./web-mirror -depth 0 https://example.com
Сохранение в другую папку:

bash
./web-mirror -output ./my_mirror https://example.com
Как это работает
Программа загружает HTML начальной страницы.

Парсит HTML, извлекает:

Ссылки <a href="..."> — для рекурсивного обхода (страницы).

Ресурсы (img, script, link[rel="stylesheet"]) — для скачивания.

Заменяет оригинальные URL на локальные относительные пути.

Сохраняет изменённый HTML в директорию output/домен/....

Рекурсивно повторяет для всех найденных страниц (в пределах глубины и домена).

Параллельно скачивает ресурсы.

Структура локального зеркала
text
site/
└── example.com/
    ├── index.html
    ├── about/
    │   └── index.html
    ├── css/
    │   └── style.css
    ├── images/
    │   └── logo.png
    └── js/
        └── script.js
Все ссылки внутри HTML преобразованы в относительные пути, поэтому сайт работает офлайн.

Ограничения
Обрабатываются только ресурсы, явно указанные в HTML через теги img, script, link[rel="stylesheet"]. Ресурсы, подгружаемые из CSS (фоны, шрифты), не скачиваются (для полной поддержки потребовался бы парсер CSS).

Не обрабатываются ссылки с атрибутами data-* (динамические SPA‑приложения).

Игнорируются внешние ссылки на другие домены.

Параметры запросов в URL (например, ?id=123) сохраняются в имени файла с заменой ? на _.

Обработка ошибок
При недоступности страницы или ресурса программа выводит ошибку в stderr и продолжает работу.

Таймауты предотвращают зависание.

Ошибки создания директорий или записи файлов логируются.
