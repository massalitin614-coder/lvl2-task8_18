Задача для получения времени с использованием пакета ntp

1. ntp.Time -  быстрый и удобный способ получить точное время одной строкой.
2. ntp.Query - более глубокий анализ, позволяющий изучить смещение часов, задержки, уровень точности сервера и другие параметры, а также проверить валидность ответа.

Задача решена в рамках обучения.
