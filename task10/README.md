# Go Telnet Client (TCP)

Минималистичный telnet-клиент на Go (TCP only), реализованный с использованием goroutines и context.

## 📌 Описание

Программа устанавливает TCP-соединение с сервером и обеспечивает двустороннее взаимодействие:

* STDIN → отправка в сокет
* сокет → вывод в STDOUT

Поддерживает корректное завершение, таймаут подключения и обработку EOF.

## ⚙️ Запуск

```bash
go run main.go [--timeout=10s] host port
```

### Пример:

```bash
go run main.go localhost 8080
```

```bash
go run main.go --timeout=5s smtp.gmail.com 25
```

## 🔧 Параметры

| Параметр  | Описание            | По умолчанию |
| --------- | ------------------- | ------------ |
| --timeout | таймаут подключения | 10s          |

## 🧠 Архитектура

Программа использует:

* `net.Conn` — TCP соединение
* `context.Context` — управление жизненным циклом
* `goroutines` — параллельный ввод/вывод
* `channels` — координация завершения

### Потоки выполнения:

1. main:

   * устанавливает соединение
   * создаёт context
   * ждёт завершения

2. goroutine #1:

   * читает из сокета → пишет в STDOUT

3. goroutine #2:

   * читает из STDIN → пишет в сокет

## 🔚 Завершение работы

Программа завершается, если:

* пользователь нажал `Ctrl+D` (EOF)
* сервер закрыл соединение
* произошла ошибка
* истёк timeout подключения

## ⚠️ Ограничения

* не реализует telnet-протокол (IAC, negotiation)
* только TCP
* нет TLS (шифрования)

## 📚 Что изучается

* работа с TCP (`net`)
* интерфейсы `io.Reader` / `io.Writer`
* goroutines и concurrency
* context и graceful shutdown
* обработка ошибок
